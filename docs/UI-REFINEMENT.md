# 中文界面与柔和树图

## 修改范围

- 复用内置`lang_zh.txt`，新配置默认简体中文。保留其他语言、英文回退及设置中的语言选择；沿用原程序的重启后切换机制。
- 补齐四种布局名称，统一大文件、采样哈希等术语；将关于窗口和两种错误提示的英文硬编码接入资源。
- 新配置默认使用平面预设：亮度72%、饱和度45%、环境光100%、高度与缩放系数均为0。沿用18色基础色板、自动网格色及原有选中高亮；关闭立体明暗渲染，不更改布局与命中定位。
- 已有持久化语言和树图设置不重置。旧配置可在设置中选择简体中文、图表平面预设。树图显示开关沿用查看菜单中的可视化窗格开关。
- 未修改扫描、空间计算、大文件、重复文件算法或任何删除功能。

## 验证范围

- 静态检查中英文资源键完整、无重复键、格式参数一致、UTF-8有效，布局下拉框仍为四项。
- 现有云端工作流继续使用免费标准`windows-2025-vs2026`，固定xxHash校验和原Release x64工程。
- 扩展现有只读合成扫描：先显式英文，再使用默认中文；两种语言均核对文件大小、目录合计、重复分组，最终核对输入哈希不变。
- 构建和实际GUI检查结果待本轮运行后补记。未验证的视觉、缩放、语言切换及交互不得视为通过。

## 本机验收方式

1. 将新版便携包解压至新的隔离目录。已有INI会保留旧语言及配色，可在设置中切换。
2. 仅选择自行生成的合成目录，勿选择整盘或真实个人目录；不执行清理和删除。
3. 检查主菜单、设置、状态栏、大文件和重复文件视图的中文，切换英语并按提示重启，再切回中文。
4. 点击树图色块确认文件列表定位、类型图例对应，尝试缩放和恢复；隐藏并重新显示可视化窗格。
5. 在浅色、深色主题及常用文字缩放下检查菜单和设置文字无截断，确认平面色块无发光和渐变。

Windows系统提供的错误文本、Shell文件类型名称以及许可证、品牌和命令参数沿用系统或原文，不强制改写。
