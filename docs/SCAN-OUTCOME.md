# 扫描结束与结果完整性

## 根因与改动

原中文`IDS_SCAN_INCOMPLETE=扫描未完成`对应英文`Scan incomplete`，意为结果不完整，容易被理解成线程仍在扫描。

停止按钮和树图由线程/界面收尾状态控制；结果完整性来自每个目录的`ScanOutcome`，经`CItem::ReconcileScanResults`传播为祖先的`ITF_SCANERROR`。祖先自身可以枚举成功，但存在失败后代。因此按钮禁用、树图显示与结果不完整可以同时成立。

源码审计未发现普通枚举正常EOF或空目录被错误标记的证据。普通扫描会保留访问拒绝等系统错误；NTFS快扫遇到越界或不存在的子项记录会保留Partial及具体路径。尚无本机失败路径/原因，不能认定用户遇到的是访问拒绝、MFT异常或正常扫描误判。

本次不改变扫描、计数、字节计算、错误传播、权限或自动提升。仅作以下修改：

- 中文目录后缀改为“扫描不完整”，终态改为“扫描已结束（结果不完整）”。正常仍为“分析完成”，取消仍为“扫描已停止”。
- 可见GUI扫描结束后，展示直接失败位置数、最多10条受影响路径及系统错误，并说明总量可能低于实际占用。完整诊断继续保存于导出CSV/JSON的ScanOutcome、ScanError。
- 从当前根的错误分支收集原因，避免仅刷新健康兄弟目录时遗漏旧失败；祖先传播标记不重复计数。隐藏本地GUI及静默导出不新增阻塞框。
- 自绘状态栏同步窗口文本，供无障碍读取与自动化行为断言使用，不改变绘制或整体布局。

## 空间统计的含义

显示的数据仍来自已读取条目。无法读取的目录或异常记录可能缺项，空间合计可能偏低；本次没有补造数据或把不完整结果当成完整。解决错误后刷新失败分支，成功时保留原有完整性恢复机制。主动排除的目录按现有过滤语义处理，不被当成读取失败。
